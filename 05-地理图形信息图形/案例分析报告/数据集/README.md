# 基础数据集说明｜Power Centers of the Fortune 500

- 文件：`Power-Centers-of-the-Fortune-500基础数据.csv`
- 记录数：15
- 一行代表：一个大都市区
- 字段：rank（排名）、metro_area（大都市区）、revenue_usd_billion（累计营业收入数值）、unit（单位）
- 金额单位：USD billion（十亿美元）
- 数据依据：用户提供的原始信息图中可辨认的15个城市气泡标签。
- 注意：此文件仅包含15个城市的核心基础数据；图中补充说明的纽约企业数量、收入占比、公司销售额等属于不同统计口径，未混入本表。
- 质量说明：数值为从图片标签转录，尚未通过原始数据库独立核验；地图中的辅助散点没有逐个名称与数值，不纳入本表。
- 结构约束：每个单元格只存放一个字段值；不得将多个城市、数值、单位或类别拼接进同一单元格。需要多值时拆分为多行或关联表。
