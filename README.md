## 案例归档规范
- 类型目录维护总论文档，并根据新增案例实时更新案例索引、共性规律和类型边界。
- 每个案例建立独立分析报告，不将多个案例混写在同一报告中。
- 案例图片统一放入对应的“示例图”目录，文件名与案例名称一致。
- 研究报告必须记录可核实的图片、文字与数据来源；未确认的信息标注“待核实”。
- 每份报告统一分析数据结构、统计图形应用、视觉编码、信息框架、叙事框架及信息图形类型学分类。

## 新增案例步骤
1. 选择最匹配的类型目录或常用图形子目录。
2. 复制该目录的分析报告模板并按案例命名。
3. 将案例图像放入“示例图”目录。
4. 完成分析后更新对应类型总文档的案例索引和归纳。
