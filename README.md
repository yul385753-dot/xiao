## 案例归档规范
- 五类信息图形目录维护类型总论、案例索引、共性规律和类型边界；专项项目维护自身理论、方法、案例与资源。
- 每个案例建立独立分析报告，图片放入对应示例图目录，并记录作者/机构、年份、原始出处、链接及版权状态。
- 每个信息图案例应归档可追溯的基础数据集或视觉观察记录，优先使用 CSV；每行一条记录、每列一个字段、每格一个值。
- 数据说明应注明字段定义、单位、来源、统计时间、转换方法和核验状态；原始、清洗、衍生数据分开保存。
- 无法核实的信息标注“待核实”，不得补造数据或推断作者意图。
- 报告分析信息结构、视觉编码、阅读路径、叙事框架及适用的设计方法。

## 新增案例步骤
1. 判断案例所属信息组织类型；不适用时注明跨类型或暂不归类。
2. 判断采用的基础设计方法（如 ISOTYPE、Gestalt），方法标签可与信息组织类型交叉。
3. 建立独立报告，归档原图、来源和可复用数据集/视觉观察记录。
4. 更新对应类型或专项项目的索引、共性规律和修订记录。
