## 案例归档规范
- 五类信息图形目录维护各自的类型总论文档、案例索引、共性规律和类型边界。
- 独立专项项目维护自身的理论、方法、案例和资源，不混入五类类型目录。
- 每个案例建立独立分析报告，不将多个案例混写在同一报告中。
- 每个案例必须同时归档可复用的基础数据集，优先使用 CSV；数据表每行代表一条观测记录，每列代表一个字段，每个单元格只允许一个值。
- 基础数据集配套说明，注明字段定义、单位、数据来源、统计时间、转换方法及核验状态。
- 原始数据、清洗后数据和衍生数据分开保存；无法从案例中确认的数据标注待核实，不得补造。
- 案例图片统一放入对应的示例图目录，文件名与案例名称一致。
- 研究报告记录可核实的图片、文字与数据来源；未确认的信息标注“待核实”。
- 每份报告分析数据结构、统计图形应用、视觉编码、信息框架、叙事框架及适用的设计方法。

## 新增案例步骤
1. 判断案例属于五类信息组织类型中的哪一类；若不适用，注明跨类型或暂不归类。
2. 判断是否采用 ISOTYPE 等基础设计方法；方法标签可与信息组织类型交叉，但独立专项研究内容归入对应专项项目。
3. 建立独立案例报告并归档原图、来源与可复用基础数据集。
4. 更新对应类型或专项项目的索引、共性规律和修订记录。
