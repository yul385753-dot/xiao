# 02-层级型信息图

本目录仅管理层级型信息图案例，按“类型总论—单案例分析—示例图”组织。新增案例时复制案例分析模板，图片放入“示例图”，并更新类型总文档中的案例索引与归纳。

## 文件结构
- 层级型信息图概念及说明文档：总文档，随案例持续更新。
- `案例分析报告/`：每个案例一份独立分析报告。
- `示例图/`：案例原图或经授权的研究截图。
- `案例分析报告/案例分析报告模板.md`：复制使用。

## 分类边界
ISOTYPE 已独立归档为 [03-ISOTYPE信息图专项项目](../03-ISOTYPE信息图/README.md)。它属于基础设计方法与视觉语言系统，不属于层级型信息图目录，也不是五类信息组织类型中的新增一类。具体案例如同时具有层级结构并采用 ISOTYPE 方法，可在案例分析中注明两者关系，但专项理论与方法资料统一归入 03 项目。
