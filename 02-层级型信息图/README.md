# 02-层级型信息图

本目录按“类型总论—单案例分析—示例图”管理。新增案例时复制案例分析模板，图片放入“示例图”，并更新类型总文档中的案例索引与归纳。

## 文件结构
- `层级型信息图依据包含、从属、等级或重要性关系组织信息，通常由总体向局部展开，突出结构、分类与上下位关系。信息图概念及说明.md`：总文档，随案例持续更新。
- `案例分析报告/`：每个案例一份独立分析报告。
- `示例图/`：案例原图或经授权的研究截图。
- `案例分析报告/案例分析报告模板.md`：复制使用。

## 跨类型基础设计方法标签
- [ISOTYPE｜基础设计方法标签](ISOTYPE-基础设计方法标签/README.md)：ISOTYPE 是标准化图像符号的视觉表达系统，属于基础设计方法，不是独立的信息图形类型。案例应先判断信息组织类型，再判断是否采用该方法；两者可以交叉标注。
