# 04｜Gestalt 格式塔视觉规律研究

> 研究重点：理论研究与设计实践并重。当前采用 13 项规律作为仓库工作索引；这不是学界公认且封闭的“唯一 13 条定律”。

## 项目定位
格式塔（Gestalt）心理学关注人如何把视觉刺激组织为有意义的整体。视觉感知并非孤立元素的简单相加，而会依据距离、相似性、连续性、闭合、图底关系、共同运动、连接等线索形成群组与结构。本专项将理论转化为可观察、可拆解、可验证、可迁移的视觉设计方法，应用于信息图、数据可视化、品牌、海报、编辑设计、界面与导视。

## 研究目标
1. 梳理理论发展、术语定义与分类差异。
2. 建立 13 项规律的独立概念档案。
3. 收集经典图示与当代设计案例，记录可核验来源。
4. 拆解空间、形态、色彩、连接、运动、层次和图底编码。
5. 通过对照实验验证规律对分组、阅读路径、识别和理解的影响。

## 分类边界
- 格式塔原则没有跨学科、跨教材完全统一的固定数量；本目录的 13 项是便于研究和检索的工作分类。
- 前 8 项作为基础知觉组织规律；共同区域与连接类原则作为扩展分组线索；平行、同步作为补充线索。
- 统一连接与元素连接在部分文献中存在交叠。本库暂作操作性区分：前者强调多个元素共享统一视觉载体，后者强调元素之间存在明确线、边或路径。归类时必须写出具体证据。
- 平行与同步并非所有经典教材都会单独列为基本定律，案例中应注明来源和语境。
- 实际设计通常由多种规律共同作用，报告需区分主导机制与辅助机制。

## 统一研究链路
**理论概念 → 可观察视觉线索 → 知觉组织结果 → 视觉编码 → 信息理解效果 → 设计实践验证**

分析时回答：哪些元素被看作一组？依据何种线索？线索如何转为空间、形态、色彩、方向、连接或运动编码？它帮助理解了什么？移除或反转该线索后会怎样？

## 案例与数据归档
每个案例建立独立报告，记录作品、作者/机构、年份、原始出处、链接、媒介、图片来源和版权状态。逐项指出规律证据及画面位置；区分作品已知设计意图与研究者的知觉分析。含定量信息时保存可追溯原始数据；主要研究视觉组织时可建立视觉观察 CSV。不得为了表格而虚构数值。

## 设计实践要求
每次实践至少完成一个变量对照，如只改变间距、相似度、连接方式或背景明度，其余条件尽量保持一致。记录目标、假设、变量、过程、结果、反馈和修订结论。
