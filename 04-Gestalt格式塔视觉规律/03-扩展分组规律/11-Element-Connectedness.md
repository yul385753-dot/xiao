# 元素连接原则 Element Connectedness

## 1. 理论定义
元素之间存在明确的线、边、链路或直接连接时，更容易被知觉为彼此相关。

## 2. 核心知觉机制
直接连接建立可见关系；具体语义可能是关联、路径、依赖或结构，需上下文说明。

## 3. 视觉编码与设计应用
网络图、流程图、组织结构图、路线图、节点关系图和数据关系图。

## 4. 案例分析方法
记录连接对象、端点、线型、方向和交叉，检查错误连线与孤立节点。

## 5. 设计实践建议
比较直接连线、间接路径和空间邻近表达关系的效果。

## 6. 适用边界与常见误用
连接只说明视觉关联，不自动说明因果、强度或方向。

## 7. 与其他规律的关系
与连续、共同区域和统一连接相关；重点是元素间的明确连接。
